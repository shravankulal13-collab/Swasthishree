# 🏢 SWASTHISHREE LUXURY LIVING & HOSTEL MANAGEMENT SYSTEM

A full-stack, production-ready hostel and resident management portal designed for **Swasthishree**. Built with **Express.js**, **React + Vite**, and **Supabase (PostgreSQL & Storage)**.

![Swasthishree Banner](https://images.unsplash.com/photo-1555854877-bab0e564b8d5?w=1200&auto=format&fit=crop&q=80)

---

## 🌟 Key Highlights

- ⚡ **Supabase PostgreSQL & Storage**: Complete SQL schema migrations, triggers for room bed sync, and storage bucket for ID proofs/resident photos.
- 🎨 **Luxury Aesthetic UI**: Dark/Light mode theme, responsive layout, glassmorphic cards, and typography powered by Google Fonts.
- 🛏️ **Room & Bed Matrix**: Floor-by-floor occupancy visualizer with real-time bed slot indicators.
- 🧾 **Official Rent Invoices & Receipts**: One-click printable tax invoices with GST/hostel branding.
- 🛠️ **Complaints Desk**: Kanban-style maintenance issue tracker with priority tags.
- 🚪 **Visitor & Gate Log**: Real-time guest check-in and check-out tracking.
- 🍲 **Weekly Mess Menu**: 7-day breakfast, lunch, snacks, and dinner meal schedule.
- 📢 **Notice Board**: Broadcast circulars and emergency hostel announcements.

---

## 🚀 Getting Started

```bash
# 1. Install all dependencies
npm run install:all

# 2. Run backend (Port 5000)
npm run dev:backend

# 3. Run frontend (Port 5173)
npm run dev:frontend
```
